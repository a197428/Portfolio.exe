## Пройденное обучение

- Практический курс HTML и CSS: семантика, формы, Flexbox, Grid, responsive design, accessibility, BEM, анимации, Git и публикация сайтов.
- Полный курс JavaScript: основы языка, DOM и события, структуры данных, ООП, асинхронность, AJAX, модули, tooling и проектирование приложений.
- «Разработка с AI на практике для всех»: LLM, prompting, AI coding agents, GitHub, Next.js, MCP, Supabase, n8n, RAG, Cloudflare AutoRAG, Python, FastAPI, LangGraph, Chrome MV3, Langfuse и Telegram-боты.
- «Разработка с AI: автоматизация и продуктивность»: AI-агенты кодинга, MCP, контекст-инжиниринг, LangGraph, базы данных, безопасность, тестирование, Docker, автоматизация и проактивные агенты.
- «1С — Программист», включая итоговую аттестационную конфигурацию.

В резюме также указаны завершённые курсы Production-Ready AI Agents и RAG, AI Agents, and Generative AI with Python and OpenAI 2026.

## Обучение в процессе

- «Основы инженерии ИИ»: разработка и оценка AI-агента, evals, tools и улучшение качества.
- «Практический ИИ для бизнеса»: информационный поиск, генеративные модели, RAG и прикладные бизнес-сценарии.
- «LangChain: разработка LLM-приложений»: LangChain, LangGraph и устройство современных LLM-систем.

## Профессиональное чтение

Прочитанная литература охватывает HTML/CSS, JavaScript, Vue, 1С:Предприятие, AI-assisted software development, backend API architecture и AI-агентов. Сейчас Александр продолжает изучать Python, LangChain и LangGraph, проектирование AI- и мультиагентных систем, практический RAG и software craftsmanship с LLM.

Статус «в процессе» не следует представлять как завершённый курс или полностью освоенную книгу.
